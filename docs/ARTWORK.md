# Starter avatar artwork

`assets/avatar-atlas.png` was generated using the built-in image-generation tool for this project. It depicts a fictional adult, not the developer or any real user. It is an equal 3-column × 2-row atlas, rendered as six square cells. No user photo was used to create the starter artwork.

Prompt: Production sprite atlas for a walking game; six equal panels, same adult Black male with short textured hair and subtle beard, realistic high-end 3D rendering. Identical front-facing full-body pose and camera, forest green athletic t-shirt, black shorts, cream shoes. Row-major stages: exaggerated enormous round body; very heavy; medium-heavy; average; lean athletic; muscular peak athlete. Fully clothed, warm confident expression, no degrading treatment. Soft studio light, no text or borders. Each complete body fits inside its cell.

The delivered image uses a dark studio backdrop. The UI retains it and crops by frame at render time; it does not stretch one photographed body to imply genuine health changes. Personal generation uses the separate consented workflow in `supabase/functions/generate-avatar`.
